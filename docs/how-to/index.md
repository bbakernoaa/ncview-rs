  level bar, multi-file switching, session restore
- [Access remote data](access-remote-data.md) — S3/GCS/Azure locations, public
  buckets without credentials
- [Run over SSH](run-over-ssh.md) — image protocols, cell fallback, tmux quirks
- [Generate a GRIB2 manifest](generate-grib2-manifest.md) — Kerchunk /

- [Compare and export](compare-and-export.md) — difference mode, PNG/SVG/JSON
